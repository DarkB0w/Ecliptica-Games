# Ecliptica Games

Türkçe, mobil uyumlu oyun stüdyosu sitesi. Derleme veya paket kurulumu gerekmez; `index.html` doğrudan açılabilir. HTTP önizlemesi: `python -m http.server 4173`.

## Oyunlar
- **Basaban:** Android'de yayımlanan 3D Sokoban tarzı bulmaca oyunu. Gerçek logo, Google Play ekran görüntüleri, 45+ seviye ve otomatik kaydetme bilgisi, mağaza bağlantısı.
- **Kızma Arena:** Geliştirme aşamasındaki masa/parti oyunu. PC ve mobil, 2–4 oyuncu ve oyun sistemleri hedef olarak sunulur. İstanbul haritası, prototip oynanışı, masa ve mimari modelleme görüntüleri kullanılır. Çıkış tarihi veya indirme bağlantısı uydurulmaz.

## Görseller ve etkileşimler
Görseller `assets/` içinde yerel olarak tutulur. Bağlantılar JavaScript olmadan da görseli açar; JavaScript ile odak yönetimi, Escape ve kapatma düğmesi olan büyük görüntü penceresi kullanılır. Mobil menü ve azaltılmış hareket tercihi desteği bulunur. Google Fonts yüklenemezse sistem yazı tiplerine geçilir.
